# Правила репо lampa-plugins (для Claude-сессий)

Глобальный `~/.claude/CLAUDE.md` действует целиком (подпись коммитов,
журнал, всё-в-контейнерах, точечный `git add` по путям). Здесь — только
специфика репо.

## Разработка: локально, одна фича = один коммит

- Разработка идёт в рабочем дереве **без промежуточных коммитов**:
  правка → смоук → проверка в локальной лампе → готовая фича одним
  коммитом. Итерационный мусор («ещё фикс», «правка опечатки») не
  коммитится и не пушится вовсе.
- `main` — **прод**: пуш обновляет Pages (плагины у всех устройств сразу)
  и триггерит сборку образа tracker-top. Пуш — только после зелёных
  смоуков и живой проверки, и только по явной команде владельца.
- Одна фича может потрогать и плагин, и сервер, и README — это один коммит.

## Локальный контур

Команды — в README (Development → Local loop), конфиг nginx — `dev/nginx.conf`.
Суть:

- тесты — только в контейнерах (`node:24-alpine` для смоуков,
  `golang:1.27-alpine` для go test)
- tracker-top под тестом: `docker build -t tracker-top:dev tracker-top` +
  контейнер на :8355; серверные правки проверять curl'ом до лампы
  (`/top`, `/feed`, `/findbatch`, `/healthz`)
- локальная лампа: nginx-контейнер с официальным вебрутом + конфиг с прокси
  `/topapi/` → tracker-top:8355 ЗА ТЕМ ЖЕ origin — кросс-портовые запросы
  localhost Safari режет как local network (status 0 «нет сети»); маунтится
  ТОЛЬКО каталог вебрута (одиночные bind-mount файлов цепляют старый inode —
  правки не подхватываются), плагины синхронизируются копированием после
  каждой правки: `cp top.js transmission-send.js t.js plex-sync.js ~/code/lampa/`; в
  index.html вебрута дев-хук `window.TJS_DEV = true` + загрузчик локального
  /t.js — бутстрап ставит плагины с того же origin, себя (виден в
  Расширениях) и ведёт топ-сервер на same-origin `/topapi` (в dev — на
  каждом старте); браузер мака — `http://localhost:8098`, Apple TV —
  «Подмена адреса» → `http://<имя-мака>.local:8098`
- http принципиален: https-страница не грузит http-плагины и не ходит в
  http-API (mixed content); на http-странице `protocol()` лампы дефолтит в
  https (TLS-хендшейки в http-nginx, «нет подключения») — дев-бутстрап
  форсит storage `protocol=http`
- после правки плагина перезапускать приложение — лампа грузит плагины
  на старте

## Инварианты кода

- tracker-top: `cacheVer` входит в **каждый** ключ кэша; правка логики
  матчитинга/фильтров = bump `cacheVer`. `/feed` отдаёт страницу **после**
  exclude, лимит slice — 100.
- top.js: DOM-операции плашек — в try/catch; перерисовка листа фильтров —
  `setTimeout(…, 120)`; SettingsApi input обязан иметь `values: 'string'`,
  select — объект ключ→название, триггеры — строки `'true'/'false'`.
- Новый сценарий поведения фиксируется в смоук-тесте сразу, а не «потом».
